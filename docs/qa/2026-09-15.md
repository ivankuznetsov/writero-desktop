## Material behavior changes

- Split, merge and multi-block paste undo as one gesture. Code indentation, list cursors and inline Markdown formatting survive editing and round trips.
- Full shell startup succeeds. Provider presets/selections, account status, long previews and conflict lists update correctly.
- Failed saves preserve drafts during close, include pending edits in bundle exports, and cannot advance snapshot cursors past unsaved content. Interrupted mapping writes replay missing blocks safely.
- Live sync retires acknowledged operations, retains numeric server identities, preserves unseen browser changes and reconstructs paginated snapshots without losing content or lock versions.
- Credentials are bound to the API server; stale OAuth responses cannot reconnect a cleared session or launch authorization after sign-out. Fragmented loopback requests and authorization state are validated.
- Malformed bulk AI output cannot erase blocks; stale alternatives remain reviewable. Requests require durable operation records and requested images before dispatch. Provider/workspace replacement cancels obsolete work.
- Hosted credit reservations and jobs stay consistent through refusal, failed debit and ambiguous provider outcomes. Generated media cannot use the server to fetch internal-network URLs.

## Actual end-to-end evidence

### Qt client → Rails sync

The final rebuilt desktop libraries connected to the fixed Rails gateway on port45111. After 100 Unicode edits and 201 additional server creates, a two-page snapshot and reopen preserved **all 204 block IDs, order, content and lock versions**, with zero pending operations or conflicts. Evidence: `final-live-sync-stress.log` and `live-sync-stress.cpp`.

The initial real-client probe exposed bugs hidden by mocks: absent acknowledgement operation IDs caused endless resubmission until HTTP429; after that server fix, numeric block IDs still created duplicate remote blocks. Both paths now pass against actual Rails.

### Browser → native OAuth

Native AccountSession performed dynamic client registration, opened the actual Rails authorization flow, received the browser's HTTP loopback callback, exchanged the PKCE code and fetched protocol1 capabilities. Two runs succeeded against port45109. Sign-out cleared the local token. [Authenticated synthetic service screenshot](2026-09-15/service-authenticated-success.png).

### Native recovery and responsiveness

A real subprocess was killed with SIGKILL after saving 1,000 Unicode paragraphs. Reopening recovered every acknowledged paragraph and the trailing placeholder; the later unsaved edit was absent, as expected.

The actual Wayland editor held 1,000 paragraphs and received 100 native key events. Exact text verification passed. Key-to-render-wait timings: **p50 21 ms, p95 21 ms, maximum 35 ms**, below the 50 ms engineering target in this run. QtTest render-wait overhead is included; this is not an external display-latency measurement. Synchronous save took33ms in the separate C++ harness. [Native window](2026-09-15/12-native-wayland.png).

## Review and remaining limits

Final inline review covers correctness, persistence, security, API contracts, reliability, tests and maintainability. It found and fixed the coordinator's three additional defects. API cross-model review was degraded: Claude was quota-blocked and its Grok replacement returned unusable output. The initial GitHub Claude review check also failed before model work and failed again after one infrastructure retry. The final API head also failed before model usage; the job exposes no underlying provider error. Desktop Grok review timed out without a usable report. Independent cross-model coverage is therefore unavailable. API PR101 needs review-service diagnostics or maintainer review; application tests pass. See this pull request’s Checks tab for current desktop CI results.

Known limits:

- Effective remote changes clear undo/redo to prevent stale history from overwriting received content. No-op echoes preserve history; collaborative history rebasing is not implemented.
- Bundle history does not yet preserve historical media identities; failed imports may leave unreferenced cached blobs even though document/history writes roll back.
- Same-Workspace-object reopening during AI work needs more lifecycle coverage. Pointer replacement cancellation is tested.
- Real Secret Service failure behavior, third-party OAuth providers and paid AI providers were not exercised. Synthetic stubs establish protocol behavior, not provider output quality.
- Native testing ran on Linux/Wayland with Qt6.11.2. Full IME/compositor scaling, every clipboard/drag-and-drop path, other operating systems and production-scale load remain outside the demonstrated coverage.
- Not every persistence side effect shares one transaction. The reproduced cursor/content and orphaned-create recovery failures are fixed; universal crash atomicity is not claimed.
- StandardKey multiple-binding warnings remain in native test output. Failed-save tests deliberately produce database-closed warnings. Neither is counted as a defect without further behavior evidence.
