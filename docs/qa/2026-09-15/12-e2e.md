## Actual process-crash durability

Standalone harness `qa12-durability.cpp` links the integrated real Workspace and DocumentController libraries. In a temporary workspace it creates 1,000 Unicode paragraphs, edits all of them, calls acknowledged `saveNow()`, then makes one additional unsaved edit. Parent sends SIGKILL and observes child exit -9. A fresh process opens the same workspace despite the stale lock and verifies all 1,000 saved contents exactly plus the trailing empty block; the unacknowledged edit is correctly absent.

Result: PASS. This tests process death, not power loss or disk-controller failure.
